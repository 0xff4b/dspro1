# Visual assets

- `hslu-logo.svg`: official Hochschule Luzern logo, obtained from https://www.hslu.ch/-/media/campus/common/images/header/hslu-logo.svg (2026-09-21). Used for this HSLU DSPRO1 project.

- `geo_price_map.png` and `feature_importance_heatmap.png`: existing project figures from `docs/final-report/fig/`.
- Plot appearance is shared by the app and notebook through `src/plot_style.py`. Saved notebook outputs are not recalculated by a theme change.
